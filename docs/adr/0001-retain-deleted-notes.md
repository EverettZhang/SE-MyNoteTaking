# Keep a bounded collection of deleted notes for recovery

Deleting a note first hides its original record so Undo and a lightweight, restore-only Deleted notes view can recover it. The collection keeps the 10 most recently deleted notes across the current database, plus any extra notes still inside a maximum 60-second recovery protection period; after protection ends, surplus oldest records are permanently removed on the next deletion or Deleted notes visit. A full database may temporarily hold more than 10 deleted notes while users are inactive or recovery windows remain open. This replaces the initial indefinite-retention choice: it bounds retained data without breaking a recent Undo, but older notes can be lost permanently, so the delete confirmation warns before a deletion that will cause eviction.
